## Rules

- **The spec wins.** Tag tests with the section they verify (`[Spec("Row Lineage")]`, `@spec:row-lineage`);
  CI regenerates the matrix and fails on a link to a section that does not exist. Prefer the spec's
  own test vectors.
- **Resolve by field ID, never by name or position**, when reading manifests or data files.
- **Metadata files are never overwritten** (`IFileIO.WriteAsync(overwrite: false)`), and after a
  `CommitStateUnknownException` nothing written for that commit may be deleted.
- New behaviour that other engines can observe needs a cross-engine test (PyIceberg oracle, REST fixture).
- If an emulator lacks an AWS guarantee, add a shim in `emulation/moto_server.py` **and** an
  `EmulatorFidelityTests` case that runs in both modes. Never weaken a test to suit the emulator.
- **Decoders of untrusted bytes** (metadata, manifests, Puffin) follow the `Corruption` contract: bounds-check every
  length before it sizes an allocation, wrap the public entry point in `Corruption.Guard`, and add a sample to
  `CorruptionTests`.
- `tests/**/fixtures/` are committed outputs of other engines: regenerate them, never hand-edit them.
- Warnings are errors (`Directory.Build.props`).


## 🛑 Repository Conventions & Workflow Policy

1. **Squash Merge Only**: All pull requests must be merged into `main` using **Squash and Merge** exclusively.
2. **Delete Branch on Merge**: Feature branches must be automatically deleted immediately upon merge into `main`.
3. **Linear History**: Maintain a strictly linear history. Rebase feature branches onto `main` before merging.
4. **Direct Push Protection**: Direct pushes to `main` are blocked; PR mechanism required (force push allowed).
5. **Local Temp & Worktree Directory**: All temporary files, databases, and worktrees go in `/temp/` (gitignored).
6. **Gitignored Local TODO File**: A root `TODO.md` file MUST exist for local task tracking and be gitignored.
7. **Auto-Merge Enabled**: PRs may enable auto-merge (squash) so they merge automatically once required checks pass.
8. **Pinned Action SHAs**: All GitHub Actions workflows MUST use 40-character commit SHAs instead of mutable tags.
9. **Script Language Policy**: Automation scripts in `scripts/` MUST use the repository's approved language stack (C# `.cs` for .NET, with Python `.py` or shell `.sh` confined to legacy emulation, interop or tools harnesses). Alien scripting runtimes (`.ps1`) are strictly prohibited and gated by CI (via `ls-lint` in staged warning mode during transition).
